# Revised sample books and narrated videos

The six selected photographs were edited with the built-in ImageGen tool in October 2026. They depict the same fictional applicant, Tenzin Dolma. Each booklet carries visible DEMO SAMPLE / NOT VALID markings. The portrait and back covers retain the assets documented in [the original asset notes](DEMO-ASSETS.md).

The Green Book cover and page layout were informed by the [CTA Green Book explanation](https://tibet.net/support-tibet/pay-green-book/) and the redacted sample pages in the appendix of the [Tibet Justice Center India report](https://www.tibetjustice.org/wp-content/uploads/2016/09/TJCIndiaReport2016.pdf) (printed pages 177–178). The Blue Book cover was informed by the photograph on the [Office of Tibet Canberra Blue Book page](https://tibetoffice.com.au/how-to-support-the-tibetan-community-in-exile/). These references guided booklet proportions, colors, a circular cultural motif, restrained gold lettering, and denser paper forms. They do not establish that our synthetic page text or layouts are accurate reproductions.

The original generated PNGs were exported to 1200px-wide JPEGs for mobile loading. The exact applied prompts and selected files follow.

One natural landscape 4:3 phone photo, no collage, no UI, no extra objects. This is a fictional sample facsimile, never usable as a valid document.

## Sample video production

No video-generation tool was available in this session. [The authoring script](../scripts/create-demo-videos.mjs) uses macOS `say` (Samantha, 150 words/minute) and FFmpeg to assemble 18-second, 720×540, 30fps H.264/AAC narrated photo montages. Three scenes show the portrait, the matching book identity spread, and the code card, with subtle camera movement, titles, and subtitles. There is no lip-synced or live applicant recording.

Selected assets:

- [Green Book video](../public/assets/demo/sample-video.mp4)
- [Blue Book video](../public/assets/demo/sample-video-blue.mp4)
- [Green Book captions](../public/assets/demo/sample-video-green.vtt)
- [Blue Book captions](../public/assets/demo/sample-video-blue.vtt)

Narration: “Hello, my name is Tenzin Dolma. I am applying for New Tibet with my Green Book. My sample verification code is five, three, four, two, one, six. This is a fictional application for demonstration purposes.” The Blue Book clip substitutes “Blue Book”.

A complete sample-photo set uses example code **534216**, matching both clips. Existing uploaded photos and their challenge are preserved when only missing samples are added. The sample-video screen always labels the clip's code as an example. Real uploads retain a random challenge and do not receive sample labels or caption tracks.

To rebuild on macOS with FFmpeg installed:

```sh
FFMPEG_BIN=/path/to/ffmpeg node scripts/create-demo-videos.mjs
```

The authoring script creates only media assets. It does not send a message or submit an application.
