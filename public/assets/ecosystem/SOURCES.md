# Ecosystem example images

Images from the listed websites, retrieved 2026-10-08 for a directory of possible New Tibet integrations. Artwork belongs to its respective owners. These are examples only: New Tibet has no signed partnership agreements with these sites and no connected New Tibet ID sign-in. Images are served locally; selecting a tile opens the example website.

- `monlam-logo.png`: https://monlam.ai/assets/logo.png — the logo displayed on https://monlam.ai/ (180 × 180 PNG).
- `zomsa-community.png`: https://www.tibetzomsa.com/_next/image?url=%2Ftibetan-group.png&w=1080&q=75 — the community photograph displayed on https://www.tibetzomsa.com/ (1080 × 810 PNG).
- `smartvote-tibet.png`: https://tibet.smartvote.org/assets/images/Static_Sharing_smartvote_Tibet.png — the sharing graphic declared by https://tibet.smartvote.org/en/home (1200 × 630 PNG).

The Sign in with New Tibet ID preview is rendered in the app using the supplied New Tibet symbol and the app’s Inter font. It is a visual preview, not an authentication control. The directory does not implement OAuth, issue credentials, or send application information to partners. The owner confirmed that no partnership agreements have been signed. Each tile is labeled Example and the page describes potential integrations. The white outlined sign-in preview uses a compact logo, 14px label and fixed spacing inspired by familiar federated sign-in controls, with New Tibet’s own branding. Reference: https://developers.google.com/identity/branding-guidelines.
