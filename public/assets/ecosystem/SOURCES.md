# Ecosystem partner images

Images from the partners’ own websites, retrieved 2026-10-08 for the requested New Tibet partner directory. Artwork belongs to the respective partners. Images are served locally so browsing the directory does not contact partner servers; partner sites open only when a tile is selected.

- `monlam-logo.png`: https://monlam.ai/assets/logo.png — the logo displayed on https://monlam.ai/ (180 × 180 PNG).
- `zomsa-community.png`: https://www.tibetzomsa.com/_next/image?url=%2Ftibetan-group.png&w=1080&q=75 — the community photograph displayed on https://www.tibetzomsa.com/ (1080 × 810 PNG).
- `smartvote-tibet.png`: https://tibet.smartvote.org/assets/images/Static_Sharing_smartvote_Tibet.png — the sharing graphic declared by https://tibet.smartvote.org/en/home (1200 × 630 PNG).

The Sign in with New Tibet ID preview is rendered in the app using the supplied New Tibet symbol and the app’s Inter font. It is a visual preview, not an authentication control. The directory does not implement OAuth, issue credentials, or send application information to partners. Partner integration status is supplied by the project owner, rather than independently tested by this directory.
