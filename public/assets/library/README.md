# Library document sources

These PDFs are complete, unchanged copies of the source editions downloaded on 14 October 2026. `sources.json` records source URLs, credits, page counts and SHA-256 hashes. The JPG previews were rendered from the original PDF pages using Poppler; no historical content was redrawn or generated.

“Uploaded by New Tibet Foundation” identifies the prototype's curator, separately from each original author or publisher. Like counts and curator comments are explicitly labelled illustrative demo activity. User likes, comments and uploaded files stay in page memory and clear on reload.

The historical editions retain period language and perspectives. They are presented as archival sources, rather than current factual guidance. The Library reader preserves all original pages, offers page navigation, zoom and embedded text/OCR, and keeps original source links and downloads available.

PDF.js is lazy-loaded when a document is opened. Its worker, fonts, CMaps and decoder files are self-hosted in the app; licenses are included with the bundle and support assets. No external document viewer is embedded.
